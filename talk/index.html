שיחת מרווחים

אני משמיע מרווח, אתה אומר בקול מה שמעת ("שלישית גדולה", "חמישית"...), ואני עונה לך.

לחץ "התחל" כדי להתחיל
נכון 0 מתוך 0 ברצף 0
אפשר גם ללחוץ על תשובה (כשלא נוהגים)
מה אפשר להגיד

Say the interval: "minor second", "major third", "perfect fourth", "tritone", "perfect fifth", "minor sixth", "major seventh", "octave". Short forms work too ("fifth", "major 3rd", "five").
Speak after the beep.
"again" — replay · "I don't know" — hear the answer · "harder" / "easier" — change level · "stop" — finish.

המרווח כמספר: "שנייה גדולה", "שלישית קטנה", "רביעית", "חמישית", "שישית גדולה", "שביעית קטנה", "אוקטבה", "טריטון".
עובד גם בקצרה ("חמש", "שלוש גדולה") וגם בשמות הישנים ("קווינטה", "טרצה גדולה").
דבר אחרי הצפצוף.
"שוב" — להשמיע שוב · "לא יודע" — לשמוע את התשובה · "יותר קשה" / "יותר קל" — לשנות רמה · "עצור" — לסיים.

מה שמעתי ולא הבנתי

אם משהו חוזר כאן הרבה — צלם מסך ושלח, ואלמד לזהות אותו.
